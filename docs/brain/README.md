## Keep it useful

Record dates, sources, uncertainty, outcomes, and the reason for decisions. Update an outdated fact with a clear correction; retain the history of important decisions. Git records changes. An agent draft is not user approval, and a planned workflow is not an active automation.

This folder is deliberately suitable for a public repository. Private operating records belong in access-controlled systems; public summaries should not reveal sensitive underlying data. No automatic transcript ingestion, background agents, or new integrations are installed by these documents.
