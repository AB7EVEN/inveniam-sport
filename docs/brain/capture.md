# Capture template

Created 2026-11-15. Use for public-safe observations and lessons. Store raw private research and customer conversations in an appropriately restricted system.

```text
Recorded date:
Source date (or unknown):
Public source / approved summary:
Product area:
Observation:
Type: confirmed fact / hypothesis / preference / decision / question
Evidence and limitations:
Next action:
Filed to / date:
```

## Filing

1. Preserve what the source actually said.
2. Separate observation from interpretation.
3. File durable facts in product context, decisions in decision history, and useful process lessons in the relevant playbook.
4. Add a short work-log entry for substantive results.
5. Leave unresolved questions explicit.

A customer request is evidence to evaluate, not an automatic instruction to change the product. A single anecdote is not market validation. Nothing here enables automatic recording, transcription, or publishing.
