# Workflow priorities

Created 2026-11-15. Proposed priorities for learning and reuse, not a measured financial ranking.

| Order | Workflow | Next step | Measure |
| --- | --- | --- | --- |
| 1 | Capture and close out meaningful work | Record result, evidence, lesson, and next step | Repeated corrections and time spent re-explaining |
| 2 | Player opportunity brief | Complete one real source-backed case | Human time, corrections, usefulness, and observed outcomes |
| 3 | Athlete announcement | Reuse an approved master for the next authorized announcement | Production/revision time and first-review acceptance |
| 4 | Product iteration | Turn an observed user need into a bounded change | Completion of the intended task and actual repeat usage |
| 5 | Weekly review | Select one evidence-backed improvement | Recurring failure removed or measured time saved |

## Minimal measurement

For repeated work record date, workflow, artifact, result, human minutes, attributable tool cost when available, corrections, and next improvement. Keep private financial/customer details in a restricted system; publish only suitable summaries here.

Unknown is not zero. Estimated time savings are not revenue. After several comparable runs, compare both quality and effort before automating more.

Add a warehouse, model router, scheduling service, or multi-agent fleet only when a repeated valuable workflow reveals a specific limit. No new vendor, schedule, or spending is authorized by this document.
